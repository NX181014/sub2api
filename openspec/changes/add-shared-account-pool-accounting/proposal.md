## Why

当前账号管理适合单一管理员维护，尚未记录共享号池中每个账号的上游身份、贡献人、实际上传人、采购来源与成本历史。现有 `usage_logs` 已保存用户、账号和 `total_cost`，可以复用为模型标准计价口径，但仍缺少按日、周、月或自定义周期进行成本分摊、采购回本判断及封禁损失分析的业务闭环。

本变更面向少量可信成员共同维护号池的场景：让采购成本、账号生命周期、模型等价使用价值和成员AA账单可追溯，同时保持代理请求热路径、现有余额扣费和开源版本页面结构稳定。

## What Changes

- 为账号增加上游身份、贡献人、上传人、是否参与共享核算及采购来源关联。
- 新增标准化采购来源、订单与质保信息，支持按来源分析封禁率、退款率、存活期和回本表现。
- 新增不可覆盖的成本流水，记录购买、续费、充值、价格变更、退款、换号转移和调整，以及人民币分值和服务期限。
- 新增账号生命周期事件，记录确认封禁、恢复、退款、换号和报废；换号保留关联，但成本、价值和回本始终按物理账号独立核算，临时异常继续使用现有账号运行状态。
- 新增按日、周、月和自定义区间的动态AA结算；使用同期 `usage_logs.total_cost` 作为成员用量权重。
- 新增结算草稿、锁定快照、贡献抵扣、零用量结转和分币尾差分配。
- 新增按请求日期汇率快照换算的模型等价使用价值、回本率、未回本损失、预计回本日和采购来源质量统计。
- V1 复用现有 admin 权限供可信朋友共同维护；实际产生共享池用量的活跃用户自动成为当期AA参与者，不新增平行角色体系。
- 新增“号池结算/回本”管理页面并复用现有账户、用量、表格、筛选、状态、权限、i18n和导出模式。
- 共享号池账本与现有用户余额、订阅和充值账本保持独立；本能力只统计和展示，不触发余额扣减。

## Capabilities

### New Capabilities

- `shared-pool-accounts`: 共享账号资产、采购来源、成本流水和账号生命周期。
- `shared-pool-settlement`: 动态账期、按模型标准成本加权的AA分摊、结转和锁定。
- `shared-pool-return-analysis`: 模型等价价值、单账号精确回本、封禁损失、预计回本和来源质量统计。

### Modified Capabilities

无。现有账号调度、使用日志、余额、订阅和充值语义保持原有契约。

## Impact

- **数据库**：为 accounts 增加可空字段；新增采购来源、成本流水、生命周期、估值汇率、结算、结算明细及快照表和索引。
- **后端**：在现有账号与用量服务旁增加共享号池服务和管理 API；复用 `usage_logs.account_id/user_id/total_cost/created_at`。
- **前端**：新增号池统计与管理页面；保持现有 Vue 组件、布局和视觉规范。
- **权限**：复用现有 admin 路由守卫；账号凭据仍由既有账号管理链路负责，本变更不读取或返回凭据。
- **性能**：统计只读取已落库日志并保存账单快照，不进入模型代理请求热路径。
- **升级**：新增字段均可空，现有账号需在首次正式结算前补录贡献人、来源、成本和服务期。

## Non-Goals

- 自动向成员收付款或自动变更用户余额。
- 独立号池成员/维护员角色及成员自助账单页面。
- CSV 账单导出和付款状态流转。
- 对采购平台自动下单、自动退款或自动发起售后。
- 引入多号池、多币种会计总账、税务凭证或复杂审批流。
- 用账号采购价格改变现有模型定价、用户计费或账号调度策略。
